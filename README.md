# Student Toolkit

A mobile-friendly productivity website designed to help students manage everyday tasks, finances, and academic responsibilities.

## Features

* **Task Automation Dashboard** — Organize tasks by priority and due date.
* **Budget and Expense Tracker** — Record transactions, monitor spending, and visualize expenses with weekly and monthly charts.
* **Student Productivity Planner** — Organize assignments, track deadlines, and monitor progress.
* **Local Data Storage** — Keep records saved in your browser.
* **Data Export and Backup** — Download records for backup and restoration.

## Technologies

* HTML
* CSS
* JavaScript

## Getting Started

Open `index.html` in a web browser, or visit the published website through GitHub Pages.

## Purpose

This project is a student-built learning project exploring web development, automation, data visualization, and practical digital solutions.
